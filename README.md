# 💬 ERPNext WhatsApp CRM & Automation Gateway

[![FastAPI](https://img.shields.io/badge/FastAPI-0.104+-009688.svg?style=flat&logo=fastapi)](https://fastapi.tiangolo.com)
[![ERPNext](https://img.shields.io/badge/ERPNext-v14%20%7C%20v15-blue.svg)](https://erpnext.com)
[![WhatsApp Cloud API](https://img.shields.io/badge/WhatsApp-Cloud%20API-25D366.svg?logo=whatsapp)](https://developers.facebook.com/docs/whatsapp/cloud-api)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A production-ready **FastAPI** integration gateway connecting **ERPNext & Frappe Framework** with **WhatsApp Cloud API**. Enables automated customer notifications on key ERP events (Sales Invoices, Delivery Notes, Payment Reminders) and provides an interactive WhatsApp self-service chatbot for customers.

---

## 🚀 Key Capabilities

- ⚡ **Real-Time DocStatus Triggers**: Automatically sends personalized WhatsApp notifications when a `Sales Invoice`, `Quotation`, or `Delivery Note` is submitted in ERPNext.
- 🤖 **Interactive Self-Service Chatbot**: Allows customers to reply to check outstanding balances, view their latest invoice summary, or route requests to support executives.
- 📑 **Instant PDF Delivery**: Automatically sends download links or attaches PDF copies generated by Frappe's print format engine.
- 📜 **Timeline Communication Sync**: Logs every sent and received WhatsApp message into Frappe's native `Communication` DocType so sales and accounts teams have full context in ERPNext Desk.
- 🎨 **Jinja2 Dynamic Templating**: Multi-lingual, dynamic notification templates with fallback logic.
- 🐳 **Docker-Ready**: Packaged with `Dockerfile` and `docker-compose.yml` for zero-downtime containerized deployment.

## ⚙️ Quickstart

### 1. Clone & Configure

```bash
git clone https://github.com/shyampandey1104/erpnext-whatsapp-crm.git
cd erpnext-whatsapp-crm
cp .env.example .env
```

Edit `.env` with your credentials:
```env
ERPNEXT_URL=https://your-site.frappe.cloud
ERPNEXT_API_KEY=your_api_key
ERPNEXT_API_SECRET=your_api_secret
WHATSAPP_TOKEN=EAAG...
WHATSAPP_PHONE_NUMBER_ID=102938475610293
WHATSAPP_VERIFY_TOKEN=erpnext_secret_verify_token
```

### 2. Run with Docker Compose

```bash
docker compose up -d --build
```
Interactive API documentation will be available at: `http://localhost:8080/docs`

## 🔗 ERPNext Setup (Server Script)

To trigger WhatsApp alerts on invoice submission:
1. In ERPNext Desk, search for **Server Script**.
2. Click **Add Server Script**:
   - **Script Type**: DocType Event
   - **Reference DocType**: `Sales Invoice`
   - **DocType Event**: `on_submit`
3. Paste the contents of [`scripts/frappe_server_script_hook.py`](scripts/frappe_server_script_hook.py).
4. Save and Submit!
